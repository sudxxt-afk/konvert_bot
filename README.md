# 🔄 Konvert Bot (KudexConvert) — универсальный конвертер файлов для Telegram

Бесплатный бот-конвертер без рекламы. Пришли файл — бот покажет кнопки со всеми доступными конвертациями. Видео, аудио, фото, документы, субтитры, архивы, QR-коды — всё в одном боте.

## Возможности

| Исходник | Конвертация |
|---|---|
| 🎬 Видео / ⭕️ Кружочки / 🎵 Аудио / 🎤 Голосовые | → голосовое (OGG Opus) · MP3 · WAV · M4A · FLAC · ⚡️ ускорение ×1.5 / ×2 · ✂️ обрезка · ℹ️ инфо · #️⃣ хеши |
| 🎵 Аудио / 🎤 Голосовые | → OGG (Vorbis) · 📱 рингтон M4R (первые 30 сек для iPhone) |
| 🎬 Видео / ⭕️ Кружочки | → GIF (до 15 сек) · 📦 нормализация MP4 (H.264 + AAC) · 🌐 сжатие WebM (VP9) · 🔇 убрать звук · 🩹 видео-стикер (WebM 512px, 3 сек) |
| 🖼 Фото (вкл. HEIC) | → JPEG · PNG · WebP · BMP · TIFF · ICO · 📦 сжатие до −70% · 🩹 под стикер 512px · ✨ Ч/Б · инверсия · поворот 90° · 🔍 распознать QR · ℹ️ инфо · #️⃣ хеши |
| 📄 PDF | → TXT · ✂️ по страницам (ZIP) · 📦 сжать (Ghostscript) · ℹ️ инфо · #️⃣ хеши |
| 📝 DOCX | → TXT (абзацы + таблицы) |
| 📊 XLSX / XLSM | → CSV |
| 📊 CSV | → XLSX |
| 📃 TXT | → PDF (с кириллицей) · 🔗 QR из содержимого |
| 💬 Субтитры SRT / VTT | → TXT без таймкодов |
| 🗜 ZIP | → распаковка (до 20 файлов) |

### Команды

| Команда | Описание |
|---|---|
| `/start` · `/help` | Приветствие и меню категорий |
| `/status` | Личная статистика |
| `/quiet` | Тихий режим: служебные сообщения самоудаляются, в чате остаются только файлы |
| `/qr текст` | QR-код из текста или ссылки (до 1500 символов) |
| `/merge` | Склейка до 10 PDF в один (в личке) |
| `/admin` | Админ-панель |

### Для любого файла

- ℹ️ **Инфо о файле** — тип, размер, длительность, разрешение, кодеки, битрейт (ffprobe)
- #️⃣ **Хеши MD5 / SHA256** — проверь подлинность скачанного файла

### Плюшки

- ⚡️ **«Как в прошлый раз»** — последнее действие предлагается первой кнопкой
- 📸 **Альбомы** — фото пачкой: одно меню на весь альбом, результат медиагруппой
- 💬 **В группах** — реплай на файл, и бот сконвертирует прямо в чате (вне реплая не реагирует)
- 🔗 **Инлайн** — набери `@kudexconvert_bot текст` в любом чате и получи QR-код
- 🤫 **Тихий режим** — служебные сообщения исчезают через минуту
- ⏳ **Очередь** — показывает позицию, конвертации идут параллельно (настраивается)
- 🔥 Реакция и эффект при успешной конвертации, caption с экономией размера

### Админ-панель

- 📊 Статистика: пользователи, конвертации, аптайм
- 👥 Последние пользователи
- ⚙️ Сервис: ffmpeg/ghostscript, очередь, размер tmp и БД
- 📢 Рассылка в 3 шага: любой контент → инлайн-кнопки → отправка всем с прогрессом и обработкой FloodWait

## Как это работает

1. Пользователь отправляет файл → бот определяет тип (видео / аудио / фото / документ / архив)
2. Показывает кнопки с доступными конвертациями, сгруппированные по секциям
3. Задача попадает в очередь → скачивание во временную папку → конвертация → отправка результата
4. Временные файлы удаляются, счётчик конвертаций растёт

## Лимиты

- **19 МБ** на файл — ограничение Telegram Bot API на скачивание
- Фото больше 10 МБ отправляются файлом
- Таймаут конвертации — 5 минут; очередь — 2 параллельных задачи (по умолчанию)
- ZIP — до 20 файлов за распаковку; QR — до 1500 символов; PDF-склейка — до 10 файлов
- PDF без текстового слоя (сканы) в TXT не конвертируются

## Запуск через Docker (рекомендуется)

Нужен только [Docker](https://docs.docker.com/get-docker/) — Python, ffmpeg и Ghostscript уже внутри образа.

```bash
cp .env.example .env        # вставь токен в BOT_TOKEN
docker compose up -d --build
docker compose logs -f      # смотреть логи
```

Полезные команды:

```bash
docker compose down           # остановить
docker compose up -d --build  # пересобрать после изменений
docker compose ps             # статус + healthcheck
```

Внутри образа: непривилегированный пользователь, healthcheck через Telegram API каждые 60 секунд, ротация логов. База данных хранится в Docker-томе `bot-data` — переживает перезапуски и пересборки. Временные файлы конвертации лежат в tmp-каталоге и удаляются после каждой задачи.

## Ручной запуск (без Docker)

**1. Установи [Python 3.10+](https://python.org) и ffmpeg:**

```bash
# Windows
winget install Gyan.FFmpeg

# macOS
brew install ffmpeg

# Linux (Debian/Ubuntu)
sudo apt install ffmpeg
```

**2. Получи токен у [@BotFather](https://t.me/BotFather)** (`/newbot`).

**3. Настрой проект:**

```bash
git clone https://github.com/sudxxt-afk/konvert_bot.git
cd konvert_bot
pip install -r requirements.txt
copy .env.example .env        # Windows
# или: cp .env.example .env   # Linux/macOS
```

**4. Впиши токен в `.env`** в поле `BOT_TOKEN=`

**5. Запусти:**

```bash
python bot.py
```

> 💡 Для конвертации TXT → PDF с кириллицей на не-Linux системах поставь шрифт DejaVu Sans (на Linux уже есть в пакетах; в Docker включён).

## Конфигурация (.env)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `BOT_TOKEN` | — | Токен от @BotFather (обязательно) |
| `QR_UPLOAD_CHANNEL` | — | ID/юзернейм канала для кэширования инлайн-QR (`@channel` или `-100…`) |
| `ADMIN_IDS` | — | ID админов через запятую |
| `ADMIN_USERNAMES` | `inhgalator` | Юзернеймы админов через запятую |
| `MAX_PARALLEL` | `2` | Параллельных конвертаций |
| `FFMPEG_THREADS` | `1` | Потоков на ffmpeg |
| `NICE_LEVEL` | `15` | Приоритет ffmpeg (чем больше, тем ниже нагрузка на сервер) |
| `DATA_DIR` · `TMP_DIR` · `DB_PATH` | рядом с ботом | Пути хранения |
| `ICON_*` | — | Кастомные emoji-иконки кнопок (Telegram Premium-аккаунты) |

## Структура проекта

```
bot.py                  # точка входа: команды, описание бота, polling
config.py               # конфигурация (.env), лимиты, админы
db.py                   # SQLite-статистика (aiosqlite, WAL)
keyboards.py            # inline-клавиатуры и меню категорий
Dockerfile              # образ (python 3.12-slim + ffmpeg + ghostscript)
compose.yml             # оркестрация: тома, healthcheck, ротация логов
handlers/
    start.py            # /start, /help, /status, /quiet, /qr, карточки категорий
    convert.py          # приём файлов, альбомы, обрезка, склейка PDF, отправка
    inline.py           # инлайн-режим: QR и шеринг
    admin.py            # админ-панель и рассылка
services/
    converter.py        # все конвертации: ffmpeg / Pillow / pypdf / fpdf2 / qrcode
    queue.py            # очередь задач с настраиваемой параллельностью
```
